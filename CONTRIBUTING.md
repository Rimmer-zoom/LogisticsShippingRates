# Contributing to Shipping Calculator

Thank you for your interest in contributing! Please follow these guidelines.

## How to Contribute
1. **Fork** the repository.
2. **Clone** your fork: `git clone https://github.com/<your-username>/shipping-calculator.git`
3. **Create a branch**: `git checkout -b feature/your-feature-name`
4. **Make your changes** and keep them focused on one topic.
5. **Commit** with a clear message: `git commit -m "Add short description of change"`
6. **Push** the branch: `git push origin feature/your-feature-name`
7. **Open a Pull Request** against the `main` branch and describe what you changed and why.

## Reporting Bugs and Requesting Features
Open an issue and include:
- A clear title and description
- Steps to reproduce (for bugs)
- Expected and actual behavior

## Coding Guidelines
- Write clear, readable code with comments where needed
- Test your changes before submitting
- Follow the existing code style

## Pull Request Review
Maintainers will review your pull request and may request changes. Please be responsive and respectful.

## Code of Conduct
By participating, you agree to abide by our [Code of Conduct](CODE_OF_CONDUCT.md).
