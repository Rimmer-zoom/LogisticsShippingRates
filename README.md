# Shipping Calculator

A simple web application that calculates shipping costs and delivery estimates for customers, built to support a transparent and efficient supply chain management process.

## Features
- Calculate shipping cost based on weight, distance and shipping method
- Provide estimated delivery time
- Easy to extend with new rates and rules

## Getting Started
1. Clone the repository:
   `git clone https://github.com/<Rimmer-zoom>/shipping-calculator.git`
2. Open the project folder and run the application following the instructions in the source files.
